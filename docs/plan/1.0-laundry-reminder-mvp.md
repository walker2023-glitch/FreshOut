# FreshOut 1.0 laundry reminder MVP

## Goal
Give residents a QR-accessible timer for Washer 1 and Dryer 1, with a private management link and email reminders.

## Implementation
1. Serve mobile-first machine and private session pages from one Express server.
2. Store machines and sessions in SQLite. Enforce one occupied session per machine with a partial unique index.
3. Hash random private tokens with a secret before storing them. Return the token only at session creation and in owner email links.
4. Reserve due completion reminders before email delivery so repeated worker runs cannot duplicate them. Check every 30 seconds.
5. Rate-limit anonymous owner notifications per machine to one every 10 minutes.
6. Protect minimal admin routes with a bearer token.
7. Test the API and reminder worker with Node's test runner and a stub mailer.

## Verification
Run `npm test`, `npm run check`, and a local smoke test for both machine URLs. Document SMTP, QR URLs, and deployment requirements in README.

## Known tradeoffs
Completion reminders use at-most-once delivery: a process failure after reservation may cause a missed email, but not a duplicate. For a larger deployment, use a durable email queue with provider idempotency. The timer estimates completion and does not read machine hardware.
